# Automatic Detection of AI-Generated Texts

Multilingual transformer ensemble for distinguishing machine-generated from human-written text, submitted to the CLIN33 shared task.

[Shared task article](https://clinjournal.org/clinj/article/view/182) • [Website](https://mohammadi.cv)

## Overview

This repository contains the contestant model of the Utrecht University team (Hadi Mohammadi, Anastasia Giachanou, Ayoub Bagheri) for the **CLIN33 shared task on the detection of text generated by large language models**. The task covers **English and Dutch** text across three domains — **news, reviews, and tweets** — framed as binary classification (AI-generated vs. human-written).

The system ensembles three pre-trained transformers and combines their predictions with a voting mechanism. The shared task and participating systems are described in the overview article published in the Computational Linguistics in the Netherlands Journal (Vol. 13, 2024).

## Data

The shared task datasets (per-language, per-domain dev sets such as `dev_en_news.csv`, `dev_nl_twitter.csv`, and a held-out test set) were provided by the CLIN33 organizers and are **not included** in this repository. The notebook expects these CSV files (columns `text`, `label`) in the working directory.

## Methods

Implemented in `contestant_model.ipynb` (PyTorch + Hugging Face Transformers):

- **Ensemble model** (`CustomBERTModel`) wrapping three sequence classifiers:
  - `bert-base-multilingual-cased`
  - `xlm-roberta-base`
  - `distilbert-base-multilingual-cased`
- **Voting mechanism**: the three logit sets are stacked and the final prediction is the mode across models (`torch.mode`)
- **Evaluation**: accuracy and macro F1 (`scikit-learn`) per dataset

The notebook loads a trained checkpoint (`entire_custom_bert_model.pth`), which is **not included** in the repository; it contains the inference and evaluation code.

## Results

Scores computed in the notebook on the shared task data:

| Dataset | Accuracy | Macro F1 |
|---------------------|--------|--------|
| Test set (`test_df`) | 75.83% | 75.55% |
| Dev — English news | 97.50% | 97.50% |
| Dev — English reviews | 81.50% | 81.21% |
| Dev — English Twitter | 96.00% | 96.00% |
| Dev — Dutch news | 97.00% | 97.00% |
| Dev — Dutch reviews | 84.00% | 84.00% |
| Dev — Dutch Twitter | 92.50% | 92.47% |

## How to run

```bash
git clone https://github.com/mohammadi-hadi/Automatic-Detection-of-AI-Generated-Texts.git
cd Automatic-Detection-of-AI-Generated-Texts
pip install torch transformers pandas scikit-learn
jupyter notebook contestant_model.ipynb
```

Running the notebook end-to-end requires the trained checkpoint (`entire_custom_bert_model.pth`) and the shared task CSV files, which are not distributed here.
